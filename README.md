# EndlessNet APT

Static APT repository for EndlessNet Debian and Ubuntu packages, served by GitHub Pages at `https://apt.endlessnet.ru`.

Add the repository on Debian/Ubuntu:

```sh
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://apt.endlessnet.ru/apt/unng.gpg | sudo tee /etc/apt/keyrings/endlessnet.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/endlessnet.gpg] https://apt.endlessnet.ru/apt stable main" | sudo tee /etc/apt/sources.list.d/endlessnet.list
sudo apt update
```

Install a package, for example:

```sh
sudo apt install endlessnet-client
```

Repository contents under `apt/` are generated by publishing workflows from EndlessNet project repositories. The existing `unng.gpg` signing-key filename is retained for compatibility with installed clients.
